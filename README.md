# Bing Chat Scraper & Analysis

This project automates the process of scraping responses from Bing Chat using **Selenium** and **BeautifulSoup**, stores them in CSV/DB, and performs analysis through a simple ETL pipeline.

## Features
- 🔍 Automates chat interactions with Bing Chat
- 📂 Extracts AI responses and saves them into CSV or database
- 📊 Performs analysis (word frequency, sentiment, trends)
- 🛡️ Handles rate-limiting & avoids anti-bot detection
- ⚡ Simple ETL pipeline for data processing

## Tech Stack
- **Python**
- **Selenium** (Web Automation)
- **BeautifulSoup4** (HTML Parsing)
- **Pandas** (Data Storage & Analysis)
- **Matplotlib / Seaborn** (Visualization)
